# Cognifyz Java Internship Project

## 📌 Project Overview

This repository contains the Java programming tasks completed as part of my Cognifyz internship. The project demonstrates practical Java programming, problem-solving skills, CRUD operations, temperature conversion, pattern programming, and file handling.

## 🛠️ Technologies Used

- Java
- Core Java
- Object-Oriented Programming
- File Handling
- Exception Handling
- Eclipse IDE

## 📂 Project Tasks

### Task 1 – Number Guessing Game
A Java-based number guessing game where the user attempts to guess a randomly generated number.

### Task 2 – Pattern Programs
Implementation of different programming patterns using Java loops and conditional statements.

### Task 3 – CRUD Operations
Implementation of Create, Read, Update, and Delete operations using Java.

### Task 4 – Temperature Converter
A Java program for converting temperature values between different units.

### Task 5 – File Handling
Implementation of file handling operations using Java, including reading from and writing to files.
